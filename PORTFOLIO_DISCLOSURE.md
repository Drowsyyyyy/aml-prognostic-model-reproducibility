# Portfolio and contribution disclosure

## Retrospective repository publication

This repository was assembled after the pilot analysis had been completed. It
is a portfolio-oriented publication of the final workflow and retained research
artifacts. Git was not used prospectively throughout the original analysis, so
the repository does not present a fabricated step-by-step historical commit
record.

The initial repository commit should be read as:

> Publication of a completed reproducibility pilot and its retained artifacts.

Subsequent commits, issues, and releases reflect only work performed after the
repository publication.

## AI assistance

AI assistance supported:

- research-design discussion;
- public-data acquisition and provenance tracking;
- Python code generation and debugging;
- nested-validation implementation;
- result-table and figure generation;
- methodological explanation;
- English and Korean documentation.

The project should not be described as independently completed without AI
assistance. A human user must personally reproduce, inspect, and understand the
analysis before representing it as their own technical experience.

## Faculty supervision

No faculty supervision is implied by this repository. A faculty member should
be named only if they actually reviewed or supervised the work. Any application,
CV, statement, or recommendation letter should accurately distinguish:

- AI-assisted work;
- work independently reproduced and understood by the applicant;
- work genuinely reviewed or supervised by faculty.

## Clinical status

This is a methodological pilot and not a clinical prediction tool. The results
do not establish:

- calibrated patient-level survival probabilities;
- an actionable clinical threshold;
- treatment benefit;
- decision-curve net benefit;
- a validated gene-expression biomarker;
- generalization to another cohort or laboratory.
